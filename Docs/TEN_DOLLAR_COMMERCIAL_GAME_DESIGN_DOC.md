# 가족치료 수련센터 10달러 이상 상용화 기획서

- 작성일: 2026-06-08
- 프로젝트 폴더: `99_FamilyTherapyPracticumUnity`
- 현재 실행본: `Builds/Windows/FamilyTherapyPracticum.exe`
- 기준 문서: `Docs/CURRENT_BUILD_STATUS.md`

## 1. 한 줄 기획

`가족치료 수련센터`는 가족치료를 공부하는 학생이 가상의 상담센터 수련생이 되어, 합성 가족 사례를 접수하고, 이론 렌즈를 선택하고, 회기 개입을 수행한 뒤, 슈퍼비전과 데이터 대시보드로 자신의 판단 패턴을 복기하는 교육용 비주얼노벨·경영 시뮬레이션 게임이다.

판매 목표는 단순 수업 과제물이 아니라, Steam/itch.io에서 **10달러 이상 가격을 붙여도 납득될 정도의 첫인상, 플레이 밀도, 학습 가치, 반복 가능성**을 갖춘 독립 게임이다.

## 2. 제품 포지셔닝

### 장르

- 비주얼노벨형 상담 시뮬레이션
- 상담센터 캠페인 경영
- 교육용 사례 분석 게임
- 플레이 로그 기반 학습 대시보드

### 핵심 차별점

1. 가족치료 이론을 단순 퀴즈가 아니라 실제 회기 선택으로 적용한다.
2. 한 가족을 여러 이론 렌즈로 다르게 볼 수 있게 만든다.
3. 플레이어의 선택을 로그로 남기고, 이론 편향과 오답 패턴을 대시보드로 보여준다.
4. 실제 사례나 영화/드라마 원작을 쓰지 않고, 상용화 가능한 합성 사례만 사용한다.
5. 상담을 대체하지 않고, 가족치료 교육과 수련을 위한 안전한 시뮬레이션으로 설계한다.

### 예상 가격

- 최소 목표가: 10달러
- 적정 목표가: 12.99달러
- 확장판/DLC 가능 가격:
  - 한국어 기본판: 12.99달러
  - 영어 번역판 또는 추가 사례팩 포함판: 14.99~19.99달러

10달러 이상 가격을 정당화하려면 `콘텐츠 분량`, `시각 완성도`, `교육적 신뢰`, `반복 플레이`, `데이터 export`가 모두 필요하다.

## 3. 타깃 사용자

### 1차 타깃

- 가족치료, 상담, 아동가족학, 사회복지, 심리학을 공부하는 대학생
- 가족치료 이론을 시험 공부가 아니라 사례 적용으로 연습하고 싶은 학습자
- 상담 수련 전 단계에서 회기 흐름과 개념화를 맛보고 싶은 학생

### 2차 타깃

- 상담교육자
- 가족상담 실습 수업 조교/강사
- 심리·상담 주제의 서사형 게임을 좋아하는 플레이어
- serious game, educational simulation, visual novel 팬층

### 제외할 타깃

- 실제 가족 문제 해결을 기대하는 일반 사용자
- 실제 상담/진단/치료 조언을 원하는 사용자
- 실시간 AI 상담봇을 기대하는 사용자

상용화 문구에서도 “내 가족을 진단해주는 게임”이 아니라 “가족치료 이론 적용을 연습하는 교육용 시뮬레이션”으로 명확히 포지셔닝해야 한다.

## 4. 플레이어 판타지

플레이어는 상담센터의 초보 수련생이다. 매주 새로운 가족 사례가 접수되고, 플레이어는 제한된 시간 안에 다음을 수행한다.

1. 사례 파일을 읽는다.
2. 가족 구성과 관계 패턴을 파악한다.
3. 어떤 가족치료 이론이 이 사례를 가장 잘 설명하는지 선택한다.
4. 실제 회기에서 어떤 질문과 개입을 할지 고른다.
5. 가족의 신뢰, 안전감, 통찰, 저항이 변화한다.
6. 회기 후 슈퍼바이저가 점수와 해설을 제공한다.
7. 캠페인이 진행될수록 플레이어의 이론 사용 습관이 데이터로 드러난다.

좋은 플레이 경험은 “정답 맞히기”보다 “내가 가족을 어떻게 보고 있었는지 알게 되는 느낌”을 줘야 한다.

## 5. 핵심 게임 루프

### 기본 루프

```text
센터 브리핑
-> 사례 접수
-> 가족 관계도/사례 파일 확인
-> 이론 렌즈 선택
-> 회기 장면 진행
-> 질문/개입 선택
-> 가족 반응 확인
-> 슈퍼비전 점수/해설
-> 플레이 로그 저장
-> 다음 사례 또는 대시보드 복기
```

### 하루 루프

- 오전: 신규 사례 접수 2~3건
- 오후: 회기 진행 1~2건
- 저녁: 슈퍼비전 및 학습 로그 복기
- 주말: 센터 운영 리포트, 이론별 약점 분석, 다음 주 학습 목표 설정

### 캠페인 루프

- 1장: 가족체계 기본과 사례 읽기
- 2장: Bowen, 구조적 가족치료 중심 사례
- 3장: 전략적, 경험적/Satir 중심 사례
- 4장: 정신역동, 인지행동 가족치료 중심 사례
- 5장: 해결중심, 이야기치료 중심 사례
- 6장: 복합사례, 이론 통합, 윤리 딜레마

## 6. 상용판 콘텐츠 규모

### 최소 상용판 기준

- 캠페인 6장
- 합성 가족 사례 60개
- 주요 회기 장면 180개 이상
- 선택지 700개 이상
- 가족치료 이론 9개
- 슈퍼바이저 캐릭터 9명
- 엔딩/평가 유형 8개 이상
- 플레이 로그 대시보드 2종
- 튜토리얼 1장
- 안전 고지/윤리 설명/AI 사용 설명

### 10달러 이상 가격을 위한 권장 기준

- 핵심 사례 24개는 수작업 에피소드형으로 작성
- 나머지 36개는 짧은 실습 사례로 구성
- 각 핵심 사례는 다음 구조를 가진다.
  - 접수 메모
  - 가족 구성
  - 초기 대화
  - 가족 관계도
  - 숨은 역동
  - 회기 1~2회
  - 잘못된 개입 반응
  - 적절한 개입 반응
  - 슈퍼비전 해설
  - 복기 질문

현재 빌드에는 합성 사례 60개와 이론 9개가 이미 들어가 있으나, 상용판 기준으로는 자동 생성형 문장을 핵심 사례 중심의 수작업 서사로 교체해야 한다.

## 7. 가족치료 이론 적용 설계

### 포함 이론

| 이론 | 게임 내 역할 | 주요 플레이 과제 |
| --- | --- | --- |
| 가족체계 기본 | 모든 사례의 기본 관찰 틀 | 순환적 상호작용과 피드백 찾기 |
| Bowen 다세대 | 세대 전이와 분화 분석 | 삼각관계, 정서적 단절, I-position 적용 |
| 전략적 가족치료 | 문제 유지 규칙 파악 | 시도된 해결책과 역설적 개입 구분 |
| 구조적 가족치료 | 가족 구조 재배열 | 경계, 위계, 하위체계 개입 |
| 경험적/Satir | 감정과 의사소통 탐색 | 빙산, 의사소통 유형, 일치형 소통 |
| 정신역동 가족치료 | 과거 관계와 방어 이해 | 투사, 미해결 애도, 대상관계 해석 |
| 인지행동 가족치료 | 생각-행동 패턴 수정 | 귀인, 강화, 행동계약, 소통 훈련 |
| 해결중심 가족치료 | 강점과 예외 확대 | 기적질문, 척도질문, 예외질문 |
| 이야기치료 | 문제 이야기 재구성 | 외재화, 독특한 결과, 재저작 |

### 점수 설계

각 선택은 5개 축으로 평가한다.

- 이론 적합도
- 가족 안전감
- 치료 동맹
- 가족역동 통찰
- 실행 가능성

최종 점수는 단일 정답 맞히기가 아니라, 플레이어가 선택한 이론과 사례 단서가 얼마나 일관되게 연결되는지를 본다.

## 9. 데이터와 빅데이터 과목 연결

이 프로젝트가 `아동가족트렌드와 빅데이터 분석` 과목 기말로 설득력을 가지려면 게임 자체만 보여주면 부족하다. 게임이 생성하는 데이터와 분석 output을 명확히 보여줘야 한다.

### 데이터셋 1: 사례 데이터

각 사례는 다음 변수를 가진다.

- `case_id`
- `chapter`
- `family_type`
- `presenting_problem`
- `risk_level`
- `recommended_theory`
- `dynamics_tags`
- `recommended_intervention`
- `hidden_pattern`
- `session_nodes`

분석 질문:

- 어떤 가족역동 태그가 어떤 이론과 자주 연결되는가?
- 위험도가 높은 사례는 어떤 이론 렌즈에서 더 자주 다루어지는가?
- 가족 유형별로 주로 등장하는 문제 서사는 무엇인가?

### 데이터셋 2: 플레이 로그

각 플레이는 다음 변수를 가진다.

- `session_id`
- `case_id`
- `selected_theory`
- `recommended_theory`
- `matched_recommended_theory`
- `selected_interventions`
- `score`
- `trust`
- `safety`
- `insight`
- `missed_concepts`
- `created_at`

분석 질문:

- 학습자는 어떤 이론을 과소/과대 사용하는가?
- 어떤 가족역동 태그에서 오답률이 높은가?
- 플레이어는 정서 중심 개입과 구조 중심 개입 중 어디에 치우치는가?
- 추천 이론과 다른 이론을 선택했을 때 점수는 어떻게 달라지는가?

### 대시보드

- 사례 데이터 대시보드
  - 이론별 사례 수
  - 가족 유형별 위험도
  - 가족역동 태그 분포
  - 추천 개입 분포
- 학습 로그 대시보드
  - 평균 점수
  - 추천 렌즈 일치율
  - 이론별 성공률
  - 놓친 개념 Top 10
  - 플레이어 이론 편향
  - 최근 세션 복기

## 10. 선택형 AI 슈퍼바이저

### 기본 정책

- 기본 상용판은 오프라인으로 완성되어야 한다.
- AI API가 없어도 모든 사례, 점수, 해설, 대시보드가 동작해야 한다.
- AI는 공식 점수 판정에 개입하지 않는다.

### 선택형 AI 기능

사용자가 API 키를 넣으면 다음 기능을 켤 수 있다.

- 슈퍼비전 코멘트 확장
- 플레이어 선택에 대한 추가 질문 생성
- 같은 사례를 다른 이론 렌즈로 다시 설명
- 회고 질문 생성

### 안전장치

- 실제 상담 조언 금지
- 개인정보 입력 금지
- “교육용 참고 코멘트” 표시
- AI 결과는 저장 전 사용자가 확인
- 공식 점수와 분리

## 11. 상용화 완성도 기준

### 10달러 미만으로 보이는 상태

- UI만 있고 캐릭터/배경이 없음
- 사례가 자동 생성 문장처럼 반복됨
- 선택지가 정답/오답 퀴즈처럼 단순함
- 회기 후 해설이 짧고 깊이가 없음
- 대시보드가 장식에 가까움
- 첫 30분 후 반복 플레이 이유가 없음

### 10달러 이상으로 보이는 상태

- 첫 화면부터 상담센터 세계관이 선명함
- 사례 파일과 가족 대화가 구체적이고 감정이 있음
- 이론별 슈퍼바이저 캐릭터가 기억에 남음
- 같은 사례를 다른 이론으로 다시 플레이할 이유가 있음
- 점수보다 해설이 학습 가치를 준다
- 플레이 로그 대시보드가 “내가 어떻게 생각하는 사람인지” 보여준다
- 최소 3~5시간의 실제 플레이 콘텐츠가 있다
- 발표나 수업에 바로 쓸 수 있는 export가 있다

## 12. 제품 구조

### 게임 모드

1. 캠페인 모드
   - 순서대로 사례를 진행하며 이론을 배운다.
2. 사례 실습 모드
   - 원하는 사례와 이론을 골라 반복 연습한다.
3. 이론별 훈련 모드
   - 특정 이론만 집중 훈련한다.
4. 대시보드 모드
   - 플레이 로그와 사례 데이터를 분석한다.
5. 슈퍼비전 기록실
   - 이전 회기 점수와 해설을 다시 본다.

### 엔딩/평가 유형

- 체계 관찰형 수련생

## 14. 6월 12일 발표 전략

사용자가 요구한 목표는 “완전판”이다. 다만 발표 시간 안에서는 전체를 다 보여줄 수 없으므로, 완전판의 모든 구조가 존재한다는 점과 상용화 핵심 장면을 압축해 보여줘야 한다.

### 발표 핵심 문장

> 저는 가족치료 수업에서 배운 이론을 단순 정리하지 않고, 가족 사례를 읽고, 이론 렌즈를 선택하고, 회기 개입을 수행한 뒤, 그 선택 로그를 데이터로 분석하는 Unity 기반 가족치료 수련 게임으로 구현했습니다.

### 발표 순서

1. 왜 이 프로젝트인가
   - 가족치료 이론은 외워도 사례 적용이 어렵다.
   - 그래서 적용을 연습하는 게임으로 만들었다.
2. 게임 시연
   - 사례 접수
   - 이론 렌즈 선택
   - 회기 선택
   - 슈퍼비전 점수/해설
3. 빅데이터 분석 연결
   - 플레이 로그
   - 사례 데이터셋
   - 대시보드
4. AI 협업
   - Codex/ChatGPT를 기획, 구현, QA, 문서화에 사용
   - AI가 상담을 대신하지 않고 제작과 분석을 보조
5. 윤리
   - 합성 사례
   - 실제 개인정보 없음
   - 실제 상담 대체 아님
6. 상용화 가능성
   - 10달러 이상 판매 기준
   - 비주얼 자산/콘텐츠 확장 로드맵

## 16. 리스크와 대응

### 리스크 1. 실제 상담처럼 오해될 수 있음

대응:

- 첫 실행 고지
- 상점 설명 고지
- AI 슈퍼바이저 제한
- “교육용 시뮬레이션” 표현 고정

### 리스크 2. 가족 갈등이 자극적으로 소비될 수 있음

대응:

- 사례를 낙인화하지 않음
- 가족 구성원을 악역으로 만들지 않음
- 증상보다 관계 패턴과 자원을 함께 제시

### 리스크 3. 자동 생성 사례가 반복적으로 느껴질 수 있음

대응:

- 핵심 사례 24개는 수작업 서사화
- 가족별 대화 톤과 장면 목표 분리
- 선택지에 이론별 오답 패턴 반영

### 리스크 4. 10달러 이상 가격 대비 비주얼이 부족할 수 있음

대응:

- 캐릭터 초상과 상담실 배경을 최우선 제작
- 사례 파일 UI를 고급스럽게 정리
- 슈퍼바이저 캐릭터를 브랜드 신호로 사용

### 리스크 5. 빅데이터 과목과의 연결이 약해질 수 있음

대응:

- 플레이 로그와 사례 데이터 대시보드를 발표 핵심으로 둔다.
- “게임을 만든 것”이 아니라 “게임이 분석 가능한 데이터를 생성한다”는 점을 강조한다.

## 17. 최종 완성 정의

이 프로젝트가 `10달러 이상으로 팔릴 정도`라고 말하려면 아래가 모두 충족되어야 한다.

- Windows 실행본이 안정적으로 작동한다.
- 첫 30분 플레이가 상용 게임처럼 보인다.
- 최소 3시간 이상의 콘텐츠가 있다.
- 가족치료 이론 9개가 실제 회기 선택과 슈퍼비전으로 연결된다.
- 핵심 사례 24개 이상이 수작업 서사로 구성되어 있다.
- 캐릭터 초상, 상담실 배경, 슈퍼바이저 컷인이 있다.
- 플레이 로그와 사례 데이터 export가 된다.
- HTML 대시보드가 실제 분석을 보여준다.
- 합성 데이터와 윤리 고지가 명확하다.
- 1280x720 이상 주요 해상도에서 UI가 깨지지 않는다.
- 발표자료, Q&A시트, AI 협업 로그, QA 증거가 함께 준비되어 있다.

5. 기말 제출용 발표자료와 Q&A시트를 만든다.
