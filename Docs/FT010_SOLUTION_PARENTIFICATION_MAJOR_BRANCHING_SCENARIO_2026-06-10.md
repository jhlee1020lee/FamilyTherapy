# FT-010 Solution-Focused Parentification Major Branching Scenario

## Goal

FT-010 focuses on a high-school-age older sibling carrying excessive caregiving for a younger sibling while a guardian is chronically ill. The presenting issue is caregiving overload, but the solution-focused task is to honor family survival strengths while identifying small exceptions and distributing burden without romanticizing parentification.

The player should learn to ask about what already works, what is too costly, and what small next step is possible.

## Route Model

| Route ID | Name | Entry condition | Session tone |
| --- | --- | --- | --- |
| `burden_distributed` | 부담 분산 루트 | 강점 인정 후 작은 예외와 자원 연결 | 누나의 역할이 조금 내려감 |
| `hero_parentified` | 영웅화 루트 | 청소년 돌봄 능력을 과하게 칭찬 | 부담이 미덕으로 고착 |
| `guardian_guilt` | 보호자 죄책감 루트 | 보호자 미안함에 초점이 쏠림 | 청소년이 다시 보호자를 위로 |
| `problem_rescue` | 외부 구조만 투입 루트 | 즉시 외부지원/기관 연결만 강조 | 가족 강점과 선택권이 약해짐 |

## Five-Turn Flow

```text
Common intro
-> T1: 강점을 인정하되 부담을 어떻게 볼 것인가
-> T2: 예외 장면 찾기
-> T3: 척도질문으로 부담과 가능성 확인
-> T4: 작은 분산 실험 설계
-> T5: 다음 주 자원 연결과 실패 시 복구 규칙
```

## Common Intro

```text
누나: 제가 안 하면 동생이 밥을 못 먹어요. 그래서 동아리는 그만뒀고, 학교 끝나면 바로 집에 옵니다.

보호자: 미안하다는 말밖에 못 합니다. 몸이 안 따라주니까 아이한테 자꾸 부탁하게 됩니다.

동생: 누나는 엄마처럼 잘 챙겨줘요. 그런데 가끔 갑자기 화를 내서 무서워요.

이웃 교사/지원 인물: 도움을 요청하면 연결할 수 있는 자원은 있습니다. 그런데 가족이 늘 괜찮다고 해서 깊이 들어가기 어려웠습니다.

송지후: 이 가족은 이미 많은 것을 해냈습니다. 동시에 그 강점이 한 사람의 희생으로 유지되는지 조심스럽게 봐야 합니다.
```

## T1. Initial Definition

| Choice | Player line | Route impact | Immediate response |
| --- | --- | --- | --- |
| A | "누나이 해낸 것을 인정하면서도, 그 부담이 조금이라도 덜했던 순간이 있었는지 찾아보겠습니다." | `burden_distributed +2` | 청소년이 방어를 낮추고 예외를 떠올림 |
| B | "누나이 정말 책임감 있게 가족을 지켜왔네요. 그 힘을 더 잘 사용할 방법을 보겠습니다." | `hero_parentified +2` | 칭찬처럼 들리지만 부담 역할 강화 |
| C | "보호자분의 죄책감이 가장 커 보입니다. 그 마음부터 충분히 다루겠습니다." | `guardian_guilt +2` | 보호자가 울고 청소년이 다시 위로 |
| D | "가족 내부에서 감당하기 어렵기 때문에 외부 지원부터 연결하겠습니다." | `problem_rescue +2` | 실용적이나 가족 선택권과 강점이 약해짐 |

## T2. Exception Search

### `burden_distributed`

```text
송지후: 문제가 덜했던 순간은 작아도 됩니다. 누나이 전부 하지 않아도 집이 무너지지 않았던 날이 있었나요?
누나: 지난주에 이웃 선생님이 동생을 데려다준 날은 제가 30분 늦게 와도 괜찮았어요.
보호자: 그날 아이가 덜 화냈던 것 같습니다. 저는 부탁하면 폐가 될까 봐 말을 못 했습니다.
동생: 그날 누나가 숙제할 시간이 있어서 덜 짜증냈어요.
```

Good T2 choice:

```text
"그 30분이 어떻게 가능했는지 자세히 보겠습니다. 누가 무엇을 했고, 가족은 무엇을 다르게 느꼈나요?"
```

### `hero_parentified`

```text
누나: 제가 잘하고 있다는 말은 좋은데, 그러면 계속 제가 해야 하는 거죠?
보호자: 아이가 너무 대견해서 더 미안합니다.
송지후: 강점 인정이 부담 고정으로 들리면 해결중심이 아니라 희생 유지가 됩니다.
```

Repair T2 choice:

```text
"해낸 점은 분명 강점입니다. 하지만 강점이 계속 혼자 짊어지는 이유가 되면 안 됩니다. 덜 힘들었던 예외를 찾아보겠습니다."
```

### `guardian_guilt`

```text
보호자: 제가 아프지만 않았어도 이런 일은 없었을 겁니다.
누나: 그런 말 하지 마세요. 제가 하면 되니까 괜찮아요.
동생: 보호자가 울면 누나도 조용해져요.
송지후: 죄책감이 방을 차지하면 청소년은 다시 어른을 돌보는 자리로 돌아갑니다.
```

Repair T2 choice:

```text
"죄책감은 중요한 마음이지만, 지금은 누나이 다시 보호자를 달래는 자리에 가지 않게 하겠습니다. 부담을 숫자로 확인해보겠습니다."
```

### `problem_rescue`

```text
이웃 교사/지원 인물: 지원 연결은 가능합니다. 다만 가족이 무엇을 원하고 어디까지 괜찮은지 정해야 합니다.
누나: 갑자기 누가 집에 들어오는 건 싫어요. 제가 못 하는 사람처럼 보일 것 같아요.
송지후: 외부 자원은 필요하지만, 가족이 이미 해온 것을 존중하지 않으면 저항이 생깁니다.
```

Repair T2 choice:

```text
"지원은 연결하되, 가족이 이미 잘 해온 방식과 충돌하지 않는 작은 도움부터 고르겠습니다."
```

## T3. Scaling

Core scene:

```text
송지후: 지금 부담이 0에서 10이라면 몇 점인가요?
누나: 8점이요. 그런데 동생이 밥 먹고 숙제까지 끝난 날은 6점 정도였습니다.
보호자: 저는 제가 할 수 있는 게 1도 없다고 생각했는데, 약 먹은 뒤 10분 정도는 동생 숙제를 봐줄 수 있습니다.
동생: 저는 혼자 양말이랑 준비물 챙기는 건 할 수 있어요.
송지후: 이미 8에서 6으로 내려간 예외가 있습니다. 완전 해결이 아니라 1점 낮추는 방법을 찾으면 됩니다.
```

Key choices:

```text
A. "다음 주 목표를 부담 8에서 7로 낮추는 것으로 잡고, 각자 할 수 있는 아주 작은 행동을 정하겠습니다."
B. "보호자가 더 미안해하지 않도록 누나이 조금만 더 버티는 계획을 세우겠습니다."
C. "외부 지원을 최대한 많이 넣어 누나의 역할을 바로 줄이겠습니다."
```

## T4. Core Solution-Focused Intervention

Target intervention:

```text
"이미 가능했던 30분을 다음 주에 한 번 더 만드는 실험을 하겠습니다. 동생은 준비물 하나 스스로 챙기기, 보호자는 약 먹은 뒤 10분 숙제 옆에 있기, 이웃 선생님은 주 1회 하교 동행 가능 여부 확인, 누나은 그 30분에 자기 일을 하나만 하기로 정합니다."
```

Expected response:

```text
누나: 30분이면 동아리까지는 아니어도 숙제는 할 수 있어요. 그 정도면 해볼 수 있을 것 같습니다.
보호자: 제가 10분이라도 맡을 수 있다면 미안하다는 말만 하지는 않아도 되겠네요.
동생: 준비물은 제가 할게요. 누나이 덜 화내면 좋겠어요.
```

## T5. Closure

Best closure:

```text
"다음 주 과제는 부담을 1점 낮추는 실험입니다. 성공 기준은 완벽한 돌봄이 아니라 누나이 자기 시간 30분을 확보했는지입니다. 실패하면 누가 잘못했는지 따지지 않고, 어느 연결이 끊겼는지 다시 찾습니다."
```

## Endings

| Ending | Condition | Result |
| --- | --- | --- |
| A. One Point Less | burden distributed route maintained | 가족이 강점을 유지하면서 부담을 1점 낮추는 실험을 합의 |
| B. Praised Into More Work | hero route dominant | 청소년의 돌봄 역할이 칭찬으로 고착 |
| C. Guilt Replaces Action | guilt route dominant | 보호자 죄책감이 중심이 되어 청소년이 다시 위로자 역할 |
| D. Help Without Ownership | rescue route dominant | 외부 지원은 들어오지만 가족의 선택권과 지속성이 약함 |

## Dialogue Expansion Notes

- 해결중심이라고 해서 위험을 축소하지 않는다. 부모화 위험은 계속 표시한다.
- 청소년의 강점은 인정하되 희생을 미덕화하지 않는다.
- 보호자의 죄책감은 행동 가능성으로 작게 전환한다.
- 송지후는 작은 예외, 척도, 1점 변화, 실패 시 복구 규칙을 반복한다.
