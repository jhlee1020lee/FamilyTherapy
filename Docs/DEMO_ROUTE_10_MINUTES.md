# 10분 발표 데모 루트

- 기준 빌드: `Builds/Windows/FamilyTherapyPracticum.exe`
- 추천 시작 버튼: `10분 데모 시작: FT-001`
- 데모 사례: `FT-001` 한부모 초등 자녀 가족, 등교 거부와 보호자 소진

## 목표

기말 발표에서는 게임 전체 분량보다, 가족치료 이론 적용과 빅데이터 과목 연결이 한 흐름으로 보이는 것이 중요하다. 아래 순서대로 진행하면 10분 안에 핵심 루프를 모두 보여줄 수 있다.

## 진행 순서

1. 메인 메뉴
   - 60개 합성 사례, 9개 가족치료 이론, 9명 슈퍼바이저를 보여준다.
   - `1장 사례 10개는 수작업 에피소드형`이라는 문구를 짚는다.

2. `10분 데모 시작: FT-001`
   - 접수 메모, 가족 관계도, 수련 목표, 초기 대화 발췌를 읽는다.
   - 등교 거부를 아이 개인 문제가 아니라 어머니-자녀-학교 사이의 순환 패턴으로 본다고 설명한다.

3. 이론 렌즈 선택
   - 추천 렌즈는 `가족체계 기본`.
   - 담당 슈퍼바이저 `김혜성 슈퍼바이저`의 코멘트를 보여준다.

4. 5턴 회기 선택
   - 초기 합류와 문제 정의
   - 가족역동 개념화
   - 감정과 구조 단서 확인
   - 핵심 개입 선택
   - 다음 주 과제와 복기

5. 슈퍼비전 리포트
   - 점수, 신뢰, 안전감, 통찰 지표를 보여준다.
   - 추천 이론 렌즈, 슈퍼바이저 코멘트, 복기 질문을 연결한다.

6. 대시보드와 export
   - `dashboard.html`의 빌드 콘텐츠 요약을 보여준다.
   - `case_dataset.csv`에는 사례별 이론, 위험도, 역동 태그, 가족 관계도, 복기 질문이 들어간다.
   - `player_choice_log.csv`에는 플레이어의 5턴 선택 경로가 남는다.

## 발표 멘트 핵심

- 이 프로젝트는 실제 상담을 대체하지 않는 교육용 시뮬레이션이다.
- 모든 사례는 실제 개인정보나 실제 상담 원문이 아닌 합성 데이터다.
- 가족치료 수업 내용은 이론 렌즈와 회기 선택으로 구현했다.
- 빅데이터 분석 과목 연결은 플레이 로그와 사례 데이터셋 export로 구현했다.
- 한 번의 플레이가 끝나면, 학생의 이론 선택 편향과 놓친 개념을 데이터로 복기할 수 있다.
