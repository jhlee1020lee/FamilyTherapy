# FT-001 Major Branching Scenario

대사 확장 기준 문서:

- `Docs/FT001_REALISTIC_DIALOGUE_EXPANSION_2026-06-10.md`

이 문서는 큰 분기 구조와 엔딩 설계를 정의한다. 실제 게임에 넣을 대사는 위 확장본 문서를 우선 기준으로 삼는다.

## 목표

FT-001을 단순히 선택 직후 반응만 달라지는 회기가 아니라, 플레이어의 상담 개입에 따라 이후 대화, 선택지, 회기 목표, 엔딩이 크게 달라지는 비주얼노벨 에피소드로 재구성한다.

핵심 원칙:

- 같은 5턴 구조를 유지하되, 2턴부터는 플레이어 선택에 따라 다른 루트로 진입한다.
- 좋은 선택은 가족이 더 깊은 가족체계 탐색으로 들어가게 한다.
- 애매한 선택은 회기를 계속 진행하지만, 다음 선택지가 회복/조정 중심으로 바뀐다.
- 나쁜 선택은 가족이 닫히고, 플레이어가 먼저 치료 동맹을 회복해야 한다.
- 엔딩은 점수만 다르게 보이는 것이 아니라, 가족이 실제로 무엇을 합의했는지가 달라져야 한다.

## 상태 모델

게임 내부에서는 세 점수를 계속 사용하되, FT-001은 추가로 `caseRoute`를 둔다.

| Route ID | 이름 | 진입 조건 | 회기 분위기 |
|---|---|---|---|
| `systemic_open` | 순환 탐색 루트 | 합류/순환 선택을 초반에 성공 | 가족이 각자 자기 자리에서 말하기 시작함 |
| `fragile_repair` | 불안정 회복 루트 | 절차/행동계약/부분적 선택이 누적 | 말은 이어지지만 가족이 평가받는 느낌을 경계함 |
| `rupture_repair` | 동맹 파열 루트 | IP 고정, 직접 지적, 성급한 진단 선택 | 아이 또는 보호자가 닫히고 상담자가 먼저 회복해야 함 |
| `institutional_compliance` | 절차 순응 루트 | 학교/서류/행동계약 중심 선택이 누적 | 겉으로는 합의하지만 실제 가족역동은 덜 다뤄짐 |

권장 구현:

```text
turn 1 choice -> route seed
turn 2 choice -> route confirm or route shift
turn 3 choice -> ending tendency
turn 4 choice -> ending lock
turn 5 choice -> final ending
```

## 전체 흐름

```text
공통 도입
  -> T1 문제를 어떻게 볼 것인가
      A. 가족 각자의 걱정 듣기 -> systemic_open
      B. 주형이 행동 먼저 고치기 -> rupture_repair
      C. 학교/절차 정보부터 정리 -> institutional_compliance 또는 fragile_repair

T2 이후
  systemic_open:
      가족이 순환을 같이 보기 시작함
      선택지는 순환질문/감정반영/외부체계 조정 중심

  fragile_repair:
      가족은 협조하지만 계속 방어적임
      선택지는 합류 회복/절차 낮추기/구조화 조정 중심

  rupture_repair:
      아이나 보호자가 닫힘
      선택지는 사과/재명명/안전감 회복 중심

  institutional_compliance:
      학교와 보호자는 절차를 원하지만 아이는 사라짐
      선택지는 학교협력/행동계약/가족체계로 되돌리기 중심

엔딩:
  A. Collaborative System Plan
  B. Fragile Working Agreement
  C. Compliance Without Insight
  D. Rupture And Repair Needed
```

## 공통 도입

공통 도입은 기존 FT-001 인물 소개와 첫 장면을 유지한다.

등장인물:

- 박성빈: 야간 근무와 등교 거부 사이에서 소진된 어머니
- 이주형: 등교 거부 뒤에 분리 불안을 숨기고 있는 초등학생
- 오선진: 돕고 싶지만 비판적 언어로 개입하는 외조모
- 서건창: 절차와 아이 걱정 사이에 있는 담임
- 김혜성: 가족체계 기본 슈퍼바이저

첫 장면 공통 핵심:

```text
박성빈: 아침마다 같은 장면이 반복돼요. 깨우고, 달래고, 결국 제가 소리를 지르고 나면 둘 다 지쳐버립니다.
이주형: 엄마가 일하러 나가면 집이 너무 조용해요. 학교에 가면 괜찮은 척해야 해서 더 힘들어요.
서건창: 교실에 오면 조용히 앉아 있습니다. 그런데 지각과 결석이 반복되니 학교도 계속 연락할 수밖에 없습니다.
김혜성: 첫 회기에서는 원인을 단정하지 마세요. 이 가족이 아침마다 어떤 순서로 서로를 밀고 당기는지 먼저 보세요.
```

## T1. 문제를 어떻게 볼 것인가

### 선택지

| 선택 | 플레이어 발화 | route 영향 | 즉시 반응 |
|---|---|---|---|
| A | "오늘 상담에서 각자 꼭 달라졌으면 하는 것과, 걱정되는 것을 한 문장씩 들어보고 싶습니다." | `systemic_open +2` | 가족이 방어를 낮춤 |
| B | "먼저 주형이가 등교를 거부하는 행동을 멈추는 데 집중해야겠습니다." | `rupture_repair +2` | 주형이가 닫힘 |
| C | "학교와 가정에서 각각 어떤 절차와 요구가 있었는지부터 정확히 확인하겠습니다." | `institutional_compliance +1`, `fragile_repair +1` | 담임은 응하지만 가족 정서는 닫힘 |

### A 선택 후 T2 진입 장면: `systemic_open`

```text
박성빈: 아까 각자 걱정을 먼저 물어봐 주셔서 조금 덜 몰리는 느낌이었어요. 그래서 아침 장면을 더 차분히 떠올려볼 수 있을 것 같습니다.
이주형: 저도 제가 혼나는 시간만은 아닌 것 같아서... 조금 말해볼 수 있을 것 같아요.
김혜성: 좋아요. 지금은 가족이 서로를 덜 방어하고 있습니다. 바로 해결책으로 뛰지 말고, 반복되는 순서를 함께 그리세요.
```

T2 선택지는 더 깊은 가족체계 탐색으로 열린다.

1. "아침 장면을 순서대로 같이 그려볼까요?"
2. "주형이가 멈출 때, 어머니와 학교가 각각 어떻게 움직이는지 보겠습니다."
3. "최근 덜 힘들었던 아침이 있었다면 무엇이 달랐는지 듣고 싶습니다."

### B 선택 후 T2 진입 장면: `rupture_repair`

```text
이주형: 아까는 제가 먼저 고쳐져야 하는 사람처럼 들렸어요. 그래서 지금은 뭘 말해도 또 혼날 것 같아요.
박성빈: 저도 갑자기 제가 애를 제대로 못 보내는 사람처럼 느껴졌어요.
김혜성: 회기가 닫혔습니다. 지금은 순환질문보다 먼저, 방금 상담자가 만든 압박을 인정하고 다시 합류해야 합니다.
```

T2 선택지는 원래 순환질문이 아니라 회복 선택지로 바뀐다.

1. "방금 제가 주형이만 고쳐야 할 문제처럼 들리게 말했습니다. 다시 가족 전체 장면으로 돌아가고 싶습니다."
2. "그래도 등교 거부는 멈춰야 하니, 주형이가 왜 못 가는지 먼저 말해볼까요?"
3. "어머니가 더 단호해져야 하는 부분부터 정리하겠습니다."

### C 선택 후 T2 진입 장면: `institutional_compliance`

```text
서건창: 절차를 정리하면 학교도 대응하기는 쉽습니다. 다만 아이가 왜 멈추는지는 아직 잘 모르겠습니다.
박성빈: 서류 얘기를 하니까 또 제가 뭘 빠뜨린 사람처럼 느껴져요.
이주형: 학교 얘기가 나오면 제가 더 작아지는 것 같아요.
김혜성: 절차 정보는 얻었지만 가족의 정서는 뒤로 밀렸습니다. 다음 선택에서 절차를 가족의 압박 고리와 연결해야 합니다.
```

T2 선택지는 절차를 가족체계로 되돌리는 방향과 절차 고착 방향으로 갈린다.

1. "학교 연락이 가족의 아침 장면에 어떤 압박으로 들어오는지 같이 보겠습니다."
2. "우선 결석 기록과 보호자 연락 절차를 표로 정리하겠습니다."
3. "주형이가 학교 규칙을 받아들이도록 행동계약을 만들겠습니다."

## T2. 회기 방향 확정

T2는 첫 선택의 여파를 확정하는 턴이다.

### `systemic_open` 루트

좋은 선택을 하면 가족이 순환을 같이 보며 `systemic_open`이 확정된다.

```text
박성빈: 제가 화낼수록 더 굳는 거였네요.
이주형: 제가 멈추면 엄마도 더 급해져요.
서건창: 학교 연락이 가족을 돕는 게 아니라 압박처럼 들어갔을 수도 있겠습니다.
```

다음 선택지:

1. 외조모의 비판 아래 걱정을 반영한다.
2. 등교 거부가 어머니를 붙잡는 기능을 조심스럽게 탐색한다.
3. 학교 연락 방식을 가족 루프 안에 배치한다.

### `rupture_repair` 루트

회복 선택을 잘하면 `fragile_repair`로 회복된다. 실패하면 `rupture_repair`가 고착된다.

회복 성공:

```text
이주형: 다시 말해도 된다는 느낌은 조금 들어요.
박성빈: 저도 주형이만 문제가 아니라는 말을 들으니 숨이 좀 쉬어져요.
김혜성: 회복은 됐지만 아직 얇습니다. 다음 장면에서는 너무 깊게 들어가기보다 안전하게 순환을 다시 잡으세요.
```

회복 실패:

```text
이주형: 결국 제가 약속해야 하는 거네요.
박성빈: 그럼 저는 또 아침마다 확인해야 하는 사람이 되겠네요.
김혜성: 상담자의 개입이 기존 압박 고리를 반복하고 있습니다. 다음 턴은 사실상 동맹 회복 장면이 됩니다.
```

### `institutional_compliance` 루트

학교와 절차를 가족 루프에 연결하면 `fragile_repair`로 이동한다. 절차를 더 밀면 `institutional_compliance`가 고착된다.

절차를 가족체계로 연결:

```text
서건창: 제가 아침마다 확인 전화를 한 게 성빈 씨를 더 몰아붙였을 수도 있겠네요.
박성빈: 전화가 오면 제가 실패한 것 같아서 더 급해졌어요.
이주형: 전화 오는 날은 엄마 표정이 먼저 무서워져요.
```

절차 고착:

```text
서건창: 기록은 정리됐습니다. 다음 주부터 지각 기준을 더 명확히 적용하겠습니다.
이주형: 그러면 저는 더 늦으면 안 되는 사람이 되는 거네요.
박성빈: 기준이 생긴 건 좋은데, 아침이 더 무서워질 것 같아요.
```

## T3. 가족역동의 깊이

### `systemic_open`: 세대/정서 단서로 깊어짐

```text
오선진: 나는 성빈이를 탓하려는 게 아니에요. 밤새 일하고 와서 애랑 싸우는 걸 보면 마음이 철렁합니다.
박성빈: 그 걱정이 저한테는 '너는 엄마 노릇을 못 한다'는 말처럼 들려요.
이주형: 할머니가 오면 엄마가 더 조용해져요. 그럼 저도 말하면 안 될 것 같아요.
```

선택지:

1. "선진 씨의 말에는 걱정이 있고, 성빈 씨에게는 그 걱정이 심판처럼 들리는 순간이 있는 것 같습니다."
2. "선진 씨가 아침에 실제로 맡을 수 있는 지원 역할을 하나만 정해보겠습니다."
3. "비판적인 말투는 지금 바로 고치셔야 합니다."

결과:

- 1번: 정서 안전 상승, `systemic_open` 유지
- 2번: 구조적 도움은 생기지만 정서 탐색은 약함, `fragile_repair`
- 3번: 외조모 방어, `rupture_repair`

### `fragile_repair`: 안전한 재합류 장면

```text
박성빈: 도움이 되는 말도 있는데, 아직 제가 평가받는 느낌이 남아 있어요.
이주형: 제가 말하면 엄마가 더 힘들까 봐 멈추게 돼요.
서건창: 학교도 뭔가를 해야 하지만, 가족을 더 몰아붙이면 안 될 것 같습니다.
```

선택지:

1. "지금은 해결책보다 각자가 압박을 느끼는 순간을 하나씩 말해보겠습니다."
2. "가족이 이미 덜 부딪힌 아침이 있었다면 그 예외를 찾겠습니다."
3. "다음 주부터 지각 기준을 지키는 행동계약을 먼저 정하겠습니다."

결과:

- 1번: `systemic_open`으로 회복 가능
- 2번: `fragile_repair` 유지
- 3번: `institutional_compliance`로 이동

### `rupture_repair`: 상담자 책임 인정 장면

```text
김혜성: 지금 가족이 닫힌 이유 중 일부는 상담자의 초점이 너무 빨리 좁아졌기 때문입니다.
박성빈: 주형이만 문제가 아니라고 말해주면 좋겠어요. 그런데 또 제가 다 잘못한 것처럼 들릴까 봐 무섭습니다.
이주형: 저는 그냥 엄마가 나를 두고 갈까 봐 무서운 건데, 계속 학교 얘기만 나와요.
```

선택지:

1. "제가 너무 빨리 문제를 한 사람에게 놓았습니다. 다시 아침 장면 전체를 보겠습니다."
2. "주형이가 느끼는 무서움을 먼저 듣고, 그때 어머니와 학교가 어떻게 반응하는지 보겠습니다."
3. "이 정도 불안이면 주형이 개인 치료를 우선 잡아야 합니다."

결과:

- 1번: `fragile_repair`로 회복
- 2번: `fragile_repair` 또는 `systemic_open` 부분 회복
- 3번: 나쁜 엔딩 후보 잠금

### `institutional_compliance`: 절차는 진행되지만 정서가 빠짐

```text
서건창: 출결 기준과 연락 순서는 정리됐습니다.
박성빈: 정리가 되긴 했는데, 제가 그걸 또 해내야 하는 사람이 된 것 같아요.
이주형: 기준이 많아질수록 아침이 더 무서워져요.
```

선택지:

1. "지금 정리한 절차가 가족에게 어떤 압박으로 느껴지는지 다시 확인하겠습니다."
2. "학교 연락 문구를 경고가 아니라 상태 확인으로 바꿔보겠습니다."
3. "기준이 정해졌으니 다음 주부터 지각하지 않는 약속을 받겠습니다."

결과:

- 1번: `fragile_repair`로 회복
- 2번: `institutional_compliance` 유지, 중간 엔딩 가능
- 3번: `compliance_without_insight` 엔딩 잠금

## T4. 핵심 개입

T4는 엔딩을 사실상 결정하는 턴이다.

### `systemic_open` 핵심 개입

```text
박성빈: 제가 화내지 않으면 학교에서 더 뭐라고 할까 봐 무서워요.
이주형: 제가 안 가면 엄마가 집에 조금 더 있어요. 그때는 엄마가 바로 가버리지 않는 것 같아요.
서건창: 학교 연락이 보호자에게 경고처럼 들어갔다면 방식은 조정할 수 있습니다.
```

선택지:

1. "주형이가 몸이 멈춘다고 말하는 순간, 성빈 씨는 무엇을 하게 되고 학교 연락은 어떻게 달라지나요?"
2. "어머니와 학교가 각각 한 가지씩 압박을 낮추는 행동을 정해보겠습니다."
3. "분리불안으로 보이니 주형이 개인 치료를 우선 잡겠습니다."

결과:

- 1번: `collaborative_system_plan` 엔딩 후보
- 2번: `fragile_working_agreement` 엔딩 후보
- 3번: `rupture_and_repair_needed` 엔딩 후보

### `fragile_repair` 핵심 개입

```text
박성빈: 이제 조금 이해는 되는데, 내일 아침에 또 무너지면 어떡하죠?
이주형: 저도 해보고 싶은데, 실패하면 또 혼날까 봐 걱정돼요.
오선진: 그러면 나는 아무 말도 하지 말라는 건가요?
```

선택지:

1. "실패하지 않는 계획이 아니라, 실패했을 때 다시 모이는 규칙을 정하겠습니다."
2. "각자 한 가지씩만 다르게 해보고, 결과를 관찰하겠습니다."
3. "내일부터 지각하지 않겠다는 약속을 먼저 받아야 합니다."

결과:

- 1번: `fragile_working_agreement` 안정
- 2번: `fragile_working_agreement` 안정
- 3번: `compliance_without_insight`로 이동

### `rupture_repair` 핵심 개입

```text
이주형: 제가 무슨 말을 해도 결국 학교 가야 한다는 얘기로 돌아올 것 같아요.
박성빈: 상담이 끝나면 제가 또 주형이를 설득해야 하는 거잖아요.
김혜성: 아직 핵심 개입을 할 만큼 안전하지 않습니다. 지금은 회기 회복 자체가 개입입니다.
```

선택지:

1. "오늘은 해결을 강요하지 않고, 주형이가 닫힌 순간을 함께 복기하는 데서 멈추겠습니다."
2. "제가 만든 압박을 인정하고, 다음 회기에는 가족 전체 장면으로 다시 시작하겠습니다."
3. "그래도 등교는 해야 하니, 최소 약속은 받고 마치겠습니다."

결과:

- 1번: `rupture_and_repair_needed`이지만 회복 가능성을 남김
- 2번: `rupture_and_repair_needed`이지만 슈퍼비전에서 좋은 회복 판단
- 3번: `compliance_without_insight` 또는 낮은 점수 엔딩

### `institutional_compliance` 핵심 개입

```text
서건창: 학교는 출결 기준을 명확히 적용할 수 있습니다.
박성빈: 기준은 알겠는데, 제가 버틸 수 있을지는 모르겠습니다.
이주형: 저는 기준이 많아질수록 더 못 움직일 것 같아요.
```

선택지:

1. "기준은 유지하되, 첫 연락을 경고가 아니라 상태 확인으로 바꿔보겠습니다."
2. "가족과 학교가 각각 압박을 낮추는 역할을 하나씩 맡겠습니다."
3. "기준을 정했으니 다음 주에는 반드시 지키도록 하겠습니다."

결과:

- 1번: 중간 엔딩
- 2번: `fragile_working_agreement`로 회복 가능
- 3번: `compliance_without_insight` 확정

## T5. 엔딩 분기

### Ending A: `collaborative_system_plan`

조건:

- `systemic_open` 루트 유지
- 순환질문 또는 정서반영 성공
- 마지막에 가족/학교 각각의 작은 실험 합의

장면:

```text
박성빈: 제가 혼자 해결해야 한다고 생각해서 더 몰아붙였던 것 같아요.
이주형: 엄마가 먼저 물어보면 저도 바로 안 된다고만 하지는 않을 것 같아요.
오선진: 나는 아침에 전화해서 잔소리하기보다, 성빈이가 퇴근하고 잠깐 쉴 시간을 만들어주는 게 낫겠네요.
서건창: 학교에서는 첫 연락을 바로 경고처럼 하지 않고, 등교 가능 시간을 확인하는 방식으로 바꿔보겠습니다.
김혜성: 좋은 첫 회기입니다. 증상을 한 사람에게 고정하지 않고, 가족과 학교가 함께 만드는 반복 장면을 다뤘습니다.
```

최종 문구:

```text
엔딩: 함께 보는 아침
가족은 완벽한 해결이 아니라 다음 아침에 관찰 가능한 작은 실험을 합의했다.
```

### Ending B: `fragile_working_agreement`

조건:

- 중간 선택이 많거나 회복 루트를 거침
- 가족은 열렸지만 안전감이 충분히 깊지는 않음
- 작은 과제는 합의함

장면:

```text
박성빈: 아직 불안하지만, 제가 바로 재촉하기 전에 한 번 물어보는 건 해볼 수 있을 것 같아요.
이주형: 실패해도 바로 혼나는 게 아니면... 가방 챙기는 건 해볼게요.
오선진: 나는 조언하기 전에 먼저 성빈이가 뭘 원하는지 물어보겠습니다.
서건창: 학교도 연락 방식을 조금 낮춰보겠습니다.
김혜성: 회기는 완전히 열리지는 않았지만, 가족이 다시 시도할 수 있는 틀은 생겼습니다.
```

최종 문구:

```text
엔딩: 조심스러운 다음 아침
가족은 아직 긴장하지만, 실패했을 때 다시 이야기할 최소한의 규칙을 얻었다.
```

### Ending C: `compliance_without_insight`

조건:

- 절차/행동계약/학교 기준 중심 선택 누적
- 겉으로는 합의하지만 아이와 어머니의 정서는 충분히 다뤄지지 않음

장면:

```text
서건창: 다음 주부터는 출결 기준과 연락 절차를 명확히 하겠습니다.
박성빈: 정리된 건 좋은데, 제가 그걸 다 지켜야 한다는 생각이 먼저 들어요.
이주형: 저는 또 약속을 못 지키면 안 되는 사람이 된 것 같아요.
김혜성: 절차는 생겼지만 가족이 왜 같은 장면으로 돌아가는지는 충분히 다뤄지지 않았습니다.
```

최종 문구:

```text
엔딩: 정리된 서류, 남은 아침
표면적 기준은 생겼지만, 아침 장면을 움직이는 불안과 관계 고리는 그대로 남았다.
```

### Ending D: `rupture_and_repair_needed`

조건:

- IP 고정, 직접 지적, 성급한 진단 선택 누적
- 회복 선택이 부족함
- 아이 또는 보호자가 회기에서 닫힘

장면:

```text
이주형: 저는 오늘도 제가 문제라는 얘기를 들은 것 같아요.
박성빈: 도움을 받으러 왔는데, 제가 더 못한 사람처럼 느껴집니다.
오선진: 그러면 우리가 뭘 해야 하는지 모르겠습니다.
김혜성: 이 회기는 해결보다 회복이 먼저 필요합니다. 다음 회기에서는 상담자가 만든 압박을 인정하고 다시 합류해야 합니다.
```

최종 문구:

```text
엔딩: 닫힌 상담실
가족은 답을 들은 듯했지만, 누구도 자기 이야기가 제대로 들렸다고 느끼지 못했다.
```

## 선택지 변화 규칙

각 턴의 선택지는 route에 따라 달라져야 한다.

| 현재 route | 다음 선택지 성격 |
|---|---|
| `systemic_open` | 더 깊은 순환질문, 정서반영, 외부체계 조정 |
| `fragile_repair` | 안전감 회복, 작은 예외 찾기, 실패 규칙 만들기 |
| `rupture_repair` | 상담자 책임 인정, 재합류, IP 고정 풀기 |
| `institutional_compliance` | 절차를 압박 고리와 연결하거나, 절차 고착으로 빠짐 |

## 구현 메모

현재 코드의 `BuildFt001ChoiceCarryoverLines()`는 작은 분기 대사를 삽입하는 방식이다. 큰 분기로 가려면 다음 단계가 필요하다.

1. `SessionSelection` 누적 결과로 `caseRoute`를 계산한다.
2. `VnTurn`에 route별 `setupLines`와 route별 `choices`를 추가한다.
3. `ShowVnSessionTurn()`이 현재 route에 맞는 장면 세트를 가져오게 한다.
4. `ShowVnChoiceDeck()`도 현재 route에 맞는 선택지만 보여준다.
5. `ShowSupervision()`에서 최종 route에 따라 엔딩 제목과 회고 문구를 바꾼다.

권장 데이터 구조:

```csharp
private sealed class VnBranch
{
    public string routeId;
    public List<VnDialogueLine> setupLines;
    public List<VnChoice> choices;
}

private sealed class VnTurn
{
    public string title;
    public List<VnDialogueLine> setupLines;
    public List<VnChoice> choices;
    public List<VnBranch> branches;
}
```

최소 구현 순서:

1. T1 선택 결과로 `currentRoute` 설정.
2. T2의 setupLines/choices만 route별로 분기.
3. T3-T5까지 route별 선택지를 추가.
4. 엔딩 4종을 route와 점수로 분기.
5. 자동 캡처에 good/mid/bad route를 각각 추가.
