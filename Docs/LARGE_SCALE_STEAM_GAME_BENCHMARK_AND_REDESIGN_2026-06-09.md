## 1.5 단일 UI 기준작

이 프로젝트의 UI 디자인은 자유롭게 새로 발명하지 않는다.

2026-06-09 오후 결정으로, UI 아트의 1차 기준작은 `Eliza`로 변경한다. `Coffee Talk`는 상담실 고정 장소와 대화 리듬 참고작으로 남기되, 실제 UI 패널, 버튼, HUD, 사례 파일, 리포트 화면은 `Eliza`식 임상 상담 인터페이스를 강하게 따른다.

### 현재 최종 UI 기준: Eliza

선정 이유:

- 상담, AI, 윤리, 내담자 대화라는 주제가 가족치료 수련 게임과 가장 직접적으로 맞는다.
- 장식적인 VN UI보다 임상 기록, 상담 스크립트, 윤리 고지, 프로토콜 화면에 가까워 현재 프로젝트의 학습/상담 성격을 더 잘 살린다.
- 사용자가 명시적으로 "네가 자유롭게 디자인하지 말고 디자인 잘 뽑힌 게임을 카피"하기를 원했고, 기준작으로 `Eliza`를 선택했다.
- 현재 임시 UI의 가장 큰 문제였던 두꺼운 네모 박스, 종이 파일 장식, 앱 대시보드 느낌을 줄이는 데 적합하다.

카피할 범위:

- 화면 구성: 어두운 상담실 배경, 얇은 상단 HUD, 큰 대화/기록 패널, 작은 선택 리스트.
- 정보량: 한 화면에 많은 박스를 깔지 않고, 현재 장면에서 필요한 정보만 노출.
- 색감: 어두운 회청색/남색 배경, off-white 패널, 낮은 채도의 청록 포인트.
- 형태: 얇은 선, 절제된 버튼 행, 넓은 여백, 낮은 반투명 패널.
- 분위기: 상담/기록/윤리 프로그램 같은 차분함과 긴장.

카피하지 않을 범위:

- `Eliza`의 원본 이미지, 로고, 캐릭터, 정확한 색상값, 픽셀 레이아웃을 복제하지 않는다.
- 우리 게임의 가족치료, 한국 상담센터, 슈퍼비전, 사례 파일 구조는 유지한다.

### Coffee Talk의 남은 역할

`Coffee Talk`는 더 이상 UI 아트 기준작이 아니다. 대신 아래 요소만 참고한다.

선정 이유:

- 한 장소에 사람들이 찾아와 자기 이야기를 말하는 구조가 상담실 게임과 가장 잘 맞는다.
- 배경, 캐릭터, 하단 대화창만으로 감정과 진행을 전달하는 화면 문법이 명확하다.
- HUD와 정보 패널이 과하지 않아, 상담 장면의 몰입을 방해하지 않는다.
- 따뜻하지만 어두운 생활감이 있어 가족치료 주제와 잘 맞는다.
- 플레이어가 직접 싸우거나 이동하는 게임이 아니라, 듣고 반응하는 게임이라는 점이 같다.

카피할 범위:

- 화면 구성 비율: 배경 전체 화면, 캐릭터 중앙/좌우 배치, 하단 대화창 중심.
- 정보량: 플레이 중에는 최소 HUD만 두고, 사례 파일/수치/로그는 별도 화면으로 분리.
- 대화창 위치: 화면 하단 20~28% 영역에 고정하고 캐릭터 얼굴과 상반신을 가리지 않는다.
- 캐릭터 연출: 현재 말하는 인물은 선명하게, 나머지 인물은 약간 어둡게 처리한다.
- 장면 진행: 긴 설명문보다 짧은 대사, 표정 변화, 다음 대사 버튼으로 리듬을 만든다.
- 분위기: 따뜻한 실내 조명, 상담실의 조용한 긴장, 일상적인 고민을 듣는 톤.

카피하지 않을 범위:

- Coffee Talk의 원본 캐릭터, 배경, UI 이미지, 로고, 아이콘, 색상 조합을 그대로 복제하지 않는다.
- 커피 제조 UI를 가져오지 않는다. 우리 게임의 대응물은 `상담 개입 덱`, `사례 파일`, `슈퍼바이저 노트`다.
- 픽셀 단위 레이아웃 복제는 하지 않는다. 화면 문법과 정보 우선순위만 강하게 벤치마킹한다.

디자인 지시:

```text
UI 자유 디자인 금지.
Coffee Talk식 고정 장소 대화형 VN 화면을 1차 기준으로 삼는다.
우리 게임은 카페가 아니라 한국 가족치료 상담센터다.
따라서 Coffee Talk의 "따뜻한 공간 + 캐릭터 중심 + 하단 대화창 + 적은 HUD" 문법을 상담실, 사례 파일, 슈퍼비전 노트로 번역한다.
```

현재 게임을 갈아엎을 때는 `Eliza`를 UI 아트 기준으로 우선한다. 판단이 애매하면 더 화려한 UI보다 `Eliza`처럼 조용하고 읽기 쉬운 임상 상담 화면을 선택한다.

## 2. 현재 게임 진단

### 유지할 것

- 가족치료 이론 9개라는 학습 구조.
- 합성 사례 60개라는 콘텐츠 뼈대.
- FT-001처럼 수작업으로 쓴 회기 대사.
- 신뢰, 안전, 통찰, 품질 같은 평가 지표.
- 플레이 로그, CSV export, 학습 대시보드.
- 슈퍼바이저 캐릭터를 이론별 멘토로 쓰는 구조.

### 버리거나 대폭 줄일 것

- 첫 화면부터 업무용 대시보드처럼 보이는 정보 패널.
- 플레이 중 계속 떠 있는 큰 캐스트 목록.
- 선택지가 시험 문제처럼 보이는 카드 구조.
- 모든 사례를 같은 밀도의 텍스트 카드로 보여주는 방식.
- 캐릭터보다 지표와 파일이 먼저 보이는 화면 우선순위.
- 영어와 한국어가 섞이는 임시 UI 문구.
- 캐릭터 성별, 나이, 역할이 이미지마다 흔들리는 자산 운영.

### 지금 가장 큰 문제

현재 게임은 "가족치료를 배우는 게임"이라는 기능은 보이지만, "상용 비주얼노벨을 플레이한다"는 첫인상이 약하다. 플레이어는 상담실에 들어온 느낌보다, 분석 도구나 과제용 앱을 켠 느낌을 먼저 받는다.

## 3. UI 디자인 벤치마크

### 상용 VN의 공통 UI 원칙

- 첫 화면은 기능 버튼보다 세계관과 분위기를 먼저 보여준다.
- 플레이 화면은 배경, 캐릭터, 대화창이 기본 3요소다.
- 추가 정보는 상시 노출보다 필요할 때 열리는 패널로 처리한다.
- HUD는 작고 안정적이며, 화면의 감정선을 방해하지 않는다.
- 선택지는 "정답 고르기"가 아니라 "내가 지금 어떤 말을 할 것인가"로 보이게 만든다.

### 우리 게임 적용안

#### 메인 화면

현재:

```text
배경 + 여러 메뉴 박스 + 진행률/사례 정보
```

전환:

```text
상담센터 로비/상담실 배경
+ 오늘의 수련 파일 1개
+ 주요 슈퍼바이저 1명 또는 실루엣
+ 새 수련 시작 / 이어하기 / 사례 파일 / 기록실
```

메인 화면은 상용 게임의 타이틀 화면처럼 보여야 한다. 메뉴는 줄이고, "상담센터에 출근했다"는 감각을 먼저 만든다.

#### 회기 화면

현재:

```text
상단 HUD + 캐릭터 + 슈퍼바이저 노트 + 하단 대화창 + 여러 패널
```

전환:

```text
상담실 배경
+ 가족 캐릭터 2~4명
+ 현재 화자 강조
+ 하단 대화창
+ 작은 슈퍼바이저 코멘트 토글
+ 필요 시 사례 파일 버튼
```

슈퍼바이저 노트는 계속 보이는 강의 노트가 아니라, 짧은 컷인이나 상담자 내면 코멘트처럼 보여야 한다.

#### 선택지 화면

현재:

```text
개입 선택 카드가 학습 문제처럼 나열
```

전환:

```text
상담자 개입 덱
- 질문하기
- 반영하기
- 구조화하기
- 순환질문
- 안전 확인
- 과제 제안
```

선택지 문장은 "이론명 맞히기"가 아니라 실제 상담자 발화여야 한다.

좋은 예:

```text
"주형이가 멈추는 순간, 엄마와 학교는 각각 어떻게 움직이나요?"
```

나쁜 예:

```text
"가족체계 이론에 맞는 개입을 고르시오."
```

#### 사례 파일 화면

현재:

```text
텍스트 카드 중심
```

전환:

```text
종이 파일 + 가족 관계도 + 인물 사진 + 접수 메모 + 위험 신호 태그
```

사례 파일은 정보 덤프가 아니라 플레이 준비 화면이어야 한다. 플레이어가 "이 가족을 만나러 간다"는 감각을 가져야 한다.

## 4. 그래픽 벤치마크

### 캐릭터 그래픽

상용 VN에서 캐릭터는 단순 삽화가 아니라 게임의 얼굴이다.

필수 기준:

- 같은 캐릭터의 표정마다 얼굴, 체형, 의상, 헤어가 유지되어야 한다.
- 표정 변화는 작아도 명확해야 한다.
- 실루엣만 봐도 역할이 구분되어야 한다.
- 성별/나이/직업이 즉시 읽혀야 한다.
- 캐릭터가 배경과 같은 색온도 안에 있어야 한다.

현재 적용해야 할 교훈:

- 이주형은 남자 초등학생으로 고정한다.
- 서건창은 남자 담임교사로 고정한다.
- 박성빈은 피로와 방어가 공존하는 어머니여야 한다.
- 오선진은 악역이 아니라 걱정이 비판으로 나오는 외조모여야 한다.
- 슈퍼바이저 9명은 이론별 말투와 시각적 성격이 달라야 한다.

### 배경 그래픽

배경은 캐릭터를 올릴 무대다. 단순 예쁜 그림이 아니라 캐릭터 배치를 고려해야 한다.

필수 기준:

- 16:9.
- 좌/중/우 캐릭터 배치 공간이 비어 있어야 한다.
- 얼굴 뒤에 강한 물체나 선이 겹치지 않아야 한다.
- 상담실 낮/저녁/긴장 버전처럼 같은 장소의 감정 변화가 있어야 한다.
- 학교, 가정, 슈퍼비전실은 서로 색과 질감이 달라야 한다.

### UI 그래픽

상용 VN UI는 네모 박스가 아니라 소재감이 있다.

우리 게임의 UI 소재:

- 상담 기록지.
- 종이 파일.
- 투명 아크릴 클립보드.
- 슈퍼비전 노트.
- 이론 카드.
- 수련 평가서.

단, 너무 실제 문서처럼 만들면 다시 업무툴처럼 보인다. 게임 UI로 읽힐 만큼 여백, 테두리, 장식, 애니메이션이 필요하다.

## 5. 게임 진행 방법 벤치마크

### 새 기본 루프

현재의 `사례 선택 -> 텍스트 읽기 -> 선택지 -> 리포트` 구조를 다음처럼 바꾼다.

```text
타이틀
-> 상담센터 로비
-> 오늘의 사례 파일 수령
-> 슈퍼바이저 브리핑
-> 가족 등장인물 소개
-> 회기 1: 합류와 문제 정의
-> 개입 선택
-> 가족 반응
-> 회기 2: 숨은 순환/경계/정서 단서
-> 개입 선택
-> 회기 3: 과제/안전/다음 단계
-> 슈퍼비전 리포트
-> 수련 로그/분석
-> 다음 사례 또는 센터 로비
```

### 챕터 구조

상용판은 60개 사례를 모두 같은 방식으로 풀면 지루하다.

- 핵심 사례 24개: 캐릭터, 표정, 회기, 선택지, 반응을 수작업 제작.
- 실습 사례 36개: 짧은 사례 파일과 1회기 선택 훈련.
- 챕터는 이론별로 묶는다.

권장 챕터:

| 챕터 | 중심 이론 | 플레이 감각 |
| --- | --- | --- |
| 1장 | 가족체계 기본 | 한 사람 문제가 아니라 순환을 보기 |
| 2장 | Bowen, 구조적 | 세대/경계/위계 읽기 |
| 3장 | 전략적, Satir | 문제 유지 규칙과 감정 확인 |
| 4장 | 정신역동, 인지행동 | 방어, 귀인, 행동계약 |
| 5장 | 해결중심, 이야기치료 | 예외, 강점, 문제 외재화 |
| 6장 | 통합 사례 | 윤리, 위험, 다중 이론 선택 |

### 게임적 장치

가족치료 수업 내용을 게임으로 만들려면 다음 장치가 필요하다.

- `신뢰`: 가족이 상담자에게 말할 수 있는 정도.
- `안전`: 회기 안에서 정서적으로 버틸 수 있는 정도.
- `통찰`: 가족이 반복 패턴을 알아차리는 정도.
- `저항`: 방어, 침묵, 비난이 강해지는 정도.
- `이론 일관성`: 선택한 렌즈와 개입이 맞는 정도.
- `윤리 위험`: 안전 계획, 비밀보장, 신고 의무 등.

이 지표는 숫자로만 보여주지 말고, 가족 표정과 대사 반응으로 먼저 보여준다.

## 6. 캐릭터 디자인 벤치마크

### 가족 캐릭터

상용 VN 캐릭터는 한 줄 역할만으로 끝나면 안 된다. 각 인물은 "표면 말"과 "숨은 욕구"를 가져야 한다.

FT-001 예시:

| 인물 | 표면 말 | 숨은 욕구 | 디자인 키워드 |
| --- | --- | --- | --- |
| 박성빈 | "학교 가야지, 빨리 움직여" | 내가 나쁜 엄마처럼 보이지 않았으면 함 | 피로, 긴장, 생활 압박 |
| 이주형 | "배가 아파요" | 엄마가 나를 두고 사라지지 않았으면 함 | 작아진 자세, 불안, 등교복 |
| 오선진 | "네가 일을 줄이면 되잖아" | 딸과 손자가 무너질까 봐 무서움 | 완고함, 걱정, 세대 압박 |
| 서건창 | "학교 절차상 연락이 필요합니다" | 아이와 가족을 돕고 싶지만 제도도 지켜야 함 | 단정함, 절차, 조심스러운 걱정 |

### 슈퍼바이저

슈퍼바이저는 단순 해설자가 아니라 플레이어의 "이론별 내면 조언자"처럼 작동해야 한다.

- 김혜성: 순환, 피드백, IP 고정 방지.
- 안우진: 세대 전이, 분화, 삼각관계.
- 김윤하: 시도된 해결책, 문제 유지 규칙.
- 이정후: 경계, 위계, 하위체계.
- 김연주: 감정, 일치성, 의사소통.
- 송성문: 방어, 투사, 미해결 관계.
- 정세영: 행동계약, 귀인, 강화.
- 송지후: 예외, 강점, 척도질문.
- 박병호: 외재화, 재저작, 정체성.

각 슈퍼바이저는 말투도 달라야 한다. 같은 문체로 이론명만 바꾸면 캐릭터가 아니라 강의 슬라이드가 된다.

## 7. 대사 벤치마크

### 좋은 상용 VN 대사의 특징

- 정보와 감정이 동시에 움직인다.
- 한 줄마다 인물의 방어, 욕구, 관계가 조금씩 드러난다.
- 플레이어가 "이 사람이 왜 이렇게 말하는지" 추론하게 만든다.
- 설명문보다 대화 상황으로 보여준다.
- 침묵, 말 끊김, 돌려 말하기가 있다.

### 우리 게임 대사 원칙

#### 1. 가족치료 용어는 가족 입에서 직접 나오지 않는다

나쁜 예:

```text
"우리 가족은 순환적 상호작용 패턴 때문에 문제가 생겼어요."
```

좋은 예:

```text
"제가 다그치면 주형이가 더 굳어요. 그러면 저는 더 겁이 나서 또 소리를 질러요."
```

#### 2. 선택지는 상담자 발화여야 한다

나쁜 예:

```text
"순환질문을 사용한다."
```

좋은 예:

```text
"주형이가 말이 없어지는 순간, 어머니와 선생님은 각각 무엇을 하게 되나요?"
```

#### 3. 틀린 선택도 그럴듯해야 한다

상용 게임의 좋은 선택지는 대놓고 틀린 답이 아니라, 초보자가 실제로 할 법한 개입이어야 한다.

예시:

```text
"주형아, 학교에 가지 않으면 어떤 일이 생기는지 알고 있니?"
```

이 선택은 완전히 이상한 말은 아니지만, 초반 회기에서는 아이에게 책임을 몰아 신뢰와 안전을 낮출 수 있다.

#### 4. 반응 대사는 지표를 대신해야 한다

숫자보다 먼저 대사가 변해야 한다.

```text
신뢰 하락: "선생님도 제가 문제라고 생각하는 거죠?"
안전 상승: "그렇게 말하니까 조금 덜 혼나는 느낌이에요."
통찰 상승: "제가 엄마를 붙잡으려고 그런 건지도 모르겠어요."
저항 상승: "그런 얘기까지 해야 하나요?"
```

### UI 우선 갈아엎을 순서

1. 메인 화면을 로비/센터 타이틀로 재설계.
2. 사례 선택 화면을 "오늘의 접수 파일" 보드로 변경.
3. 회기 화면의 하단 대화창, 이름표, 선택지 카드를 상용 VN 스킨으로 교체.
4. 슈퍼바이저 노트를 컷인/토글/내면 조언 형태로 변경.
5. 대시보드는 게임 밖 분석표가 아니라 "수련 평가서"처럼 보이게 변경.

이 순서가 중요한 이유는 현재 플레이 첫인상을 망치는 문제가 `캐릭터 정체성 오류`, `조잡한 UI`, `상담실 현장감 부족`이기 때문이다.

## 10. 최종 방향

이 프로젝트는 다음처럼 바꾸는 것이 맞다.

```text
현재:
가족치료 사례 데이터베이스 + 학습 대시보드 + 일부 VN 화면

목표:
상담센터에 출근해 가족을 만나고, 대화를 듣고, 개입을 선택하고,
슈퍼바이저에게 평가받는 상용 비주얼노벨 상담 시뮬레이션
```

가장 중요한 전환은 "정보를 보여주는 프로그램"에서 "상담 장면을 플레이하는 게임"으로 바꾸는 것이다. 데이터와 분석 기능은 버리지 않는다. 다만 플레이 중에는 뒤로 숨기고, 회기가 끝난 뒤 수련 평가서와 분석실에서 보이게 한다.
