# FT001 Claude Design PPT Package

이 폴더는 Claude Design으로 `가족치료 수련 비주얼노벨` 발표 자료를 만들기 위한 FT-001 전용 패키지다. 사용자가 이미 만들어둔 PPT 템플릿을 유지하고, 이 폴더의 이미지와 원고만 끼워 넣는 방식으로 작업한다.

## 발표 목표

FT-001 `한부모 초등 자녀 가족`을 중심으로, 이 프로젝트가 단순 게임 제작물이 아니라 가족치료 수련생이 상담 장면을 관찰하고, 개입을 선택하고, 그 선택 로그를 분석할 수 있는 학습형 비주얼노벨 시스템이라는 점을 보여준다.

## 폴더 구성

- `01_recommended_insert_images`: 발표에 바로 넣을 대표 이미지 10장.
- `02_full_ft001_line_by_line_cg_50`: FT-001 회기용 line-by-line CG 전체 50장.
- `03_runtime_screenshots_1600x900`: 현재 Unity 실행 화면 캡처. 프로토타입 작동 증거로 사용.
- `04_contact_sheets_and_references`: 이미지 생산량, 캐릭터 일관성, UI/런타임 검수 과정을 보여줄 contact sheet.
- `05_notes_for_claude_design`: 생성 manifest 및 보조 문서.
- `SLIDE_CONTENT_KR.md`: 슬라이드별 내용 원고.
- `CLAUDE_DESIGN_COMMAND.md`: Claude Design에 그대로 붙여넣을 작업 지시문.
- `ASSET_SELECTION_GUIDE.md`: 어떤 이미지를 어떤 용도로 쓰면 좋은지 정리.
- `PACKAGE_FILE_INDEX.csv`: 패키지 파일 목록.

## 디자인 방향

- 16:9 발표 자료.
- 기존 템플릿의 색, 폰트, 마스터 레이아웃을 유지한다.
- 과한 장식보다 실제 게임 스크린샷과 CG를 크게 보여준다.
- 한 슬라이드에 텍스트를 많이 넣지 않는다.
- 발표자가 말로 설명할 수 있게 본문은 짧은 문장 중심으로 둔다.
- 게임 제목은 `가족치료 수련 비주얼노벨` 또는 `Family Therapy Practicum`로 표기한다.

## 주의

이 패키지는 FT-001 발표용이다. FT-002부터 FT-010까지는 아직 확장 작업 중이므로, 발표에서는 “확장 예정” 또는 “제작 중”으로만 언급한다.
