# Claude Design 작업 지시문

아래 지시문을 Claude Design에 붙여넣고, 이 폴더 전체를 자료 폴더로 제공한다.

```text
이미 만들어둔 PPT 템플릿을 사용해서 16:9 발표 자료를 만들어줘. 템플릿의 전체 색감, 폰트, 마스터 레이아웃은 유지하고, 새 템플릿을 만들지 마.

발표 주제는 "가족치료 수련 비주얼노벨: FT-001 한부모 초등 자녀 가족 사례"야. 이 자료는 기말 프로젝트 설명용이고, 핵심은 가족치료 수업에서 배운 개념을 실제 플레이 가능한 비주얼노벨 상담 시뮬레이션으로 구현했다는 점이야.

이 폴더의 `SLIDE_CONTENT_KR.md`를 기준으로 12장 내외의 발표 자료를 만들어줘. 각 슬라이드는 이미지 중심으로 구성하고, 본문 텍스트는 3-4줄 이하로 줄여줘. 발표자가 말로 설명할 수 있게 화면에는 핵심 문장만 남겨줘.

이미지 사용 우선순위:
1. `01_recommended_insert_images`의 대표 이미지
2. `03_runtime_screenshots_1600x900`의 실제 Unity 실행 화면
3. `04_contact_sheets_and_references`의 contact sheet
4. 필요할 때만 `02_full_ft001_line_by_line_cg_50`의 전체 CG 중 추가 선택

디자인 톤:
- 학술 발표와 게임 피치 사이의 균형
- 차분하고 전문적인 상담센터 분위기
- 과한 장식보다 큰 이미지, 짧은 문장, 명확한 구조
- 게임 화면/CG는 되도록 크게 보여주기

주의:
- FT-001은 현재 실제 실행 가능한 프로토타입으로 설명해줘.
- FT-002~FT-010은 아직 확장 중이므로 완성됐다고 쓰지 말고 "확장 예정/제작 중"으로 표현해줘.
- "데모"라는 단어는 최소화하고, "첫 완성 단위", "핵심 사례", "프로토타입", "확장 기준" 같은 표현을 써줘.
- stretched screenshot처럼 보이지 않게 이미지는 원본 비율을 유지해서 배치해줘.
```
